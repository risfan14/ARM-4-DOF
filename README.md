# ARM-4-DOF
ARM 4 DOF (Robotic Arm) is a robotic arm project based on the Arduino Nano, using four servo motors and two joystick modules for manual movement control. The joysticks control the arm's up-and-down movements, left-and-right rotation, and gripping mechanism to pick up and move objects.

Main components: Arduino Nano, 4 Servo Motors, and 2 Joystick Modules.
